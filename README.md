
# Amazon Clone

## Overview

This project is a front-end clone of the Amazon homepage built using HTML and CSS. It replicates the basic layout and design of Amazon, including the navigation bar, hero section, product categories, and footer. The project was created to practice web development fundamentals and improve skills in responsive page design and user interface development.

## Features

* Amazon-inspired homepage layout
* Responsive navigation bar
* Search bar interface
* Hero/banner section
* Product category cards
* Footer section with multiple links
* Font Awesome icons integration
* Clean and organized design

## Concepts Used

* Semantic HTML structure
* CSS Flexbox
* CSS Grid
* Responsive Web Design
* Box Model
* Positioning and Alignment
* Hover Effects
* External Libraries (Font Awesome)

## How It Works

The website is structured using HTML elements to create different sections such as the navigation bar, hero area, shopping categories, and footer. CSS is used to style these components, control layout positioning, and improve the visual appearance. Font Awesome icons are integrated through a CDN link to provide professional-looking icons throughout the interface.

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/farihanusratkhan/amazon-clone-html-css.git
```

2. Open the project folder.

3. Double-click `index.html` or open it in any modern web browser.

No additional installation or dependencies are required.
